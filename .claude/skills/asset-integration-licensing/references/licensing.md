# Licensing notes for game assets (not legal advice)

| Licence | Commercial use | Modify | Attribution | Notes |
| --- | --- | --- | --- | --- |
| CC0 1.0 | yes | yes | not required (appreciated) | safest; still record source |
| CC BY 4.0 | yes | yes | **required** (author, title, licence, link, changes) | put in credits screen/file |
| CC BY-SA 4.0 | yes | yes | required | adaptations must be BY-SA: problematic inside a game's asset set; ask before using |
| CC BY-NC (any) | **no** | yes | required | excludes commercial plans (ads, sales, paid hosting may count) |
| CC BY-ND (any) | yes | **no** | required | no edits, not even re-colouring |
| MIT / BSD / Apache-2.0 (code, some assets) | yes | yes | keep the licence notice | fonts/code libs |
| SIL OFL 1.1 (fonts) | yes | yes | keep licence; reserved font names on modified versions | can't sell the font alone |
| "Royalty-free" marketplace | per store EULA | usually | varies | often forbids redistributing source files in open repos |
| GPL (tools like Blender, GIMP) | output belongs to you | — | — | the tool's licence does not cover your renders/exports |

Open-source repository + store-licensed assets: many marketplace EULAs forbid publishing the raw files in a
public repo. Check before committing.

Credits line format: `"Title" by Author (link), licensed CC BY 4.0 (link). Modified: recoloured, trimmed.`
